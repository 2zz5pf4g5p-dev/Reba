Reba v20 (Neon PostgreSQL + Render)

1. Extract package.json and server.js from reba-v20.zip.
2. Upload/replace them in your GitHub repository (2zz5pf4g5p-dev/Reba on branch main).
3. Ensure DATABASE_URL is set in Render environment variables pointing to your Neon database.
4. Render will install dependencies (including pg) and start server.js.
